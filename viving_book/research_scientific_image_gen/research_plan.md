# Research Plan: High-Quality Scientific Explanatory Image Generation with AI/Agents

## Main Question
What are the best approaches to generate HIGH QUALITY scientific explanatory images using AI models, agent skills, and agentic pipelines?

## Subtopic 1: Best AI Models for Scientific Image Generation
Compare leading image generation models (Gemini 2.5 Flash Image, DALL-E 3, Midjourney, Stable Diffusion 3, Flux, Ideogram) specifically for scientific/technical diagrams. Focus on: text rendering accuracy, diagram quality, equation rendering, schematic fidelity.

## Subtopic 2: Agentic Pipelines for Image Generation
Research multi-step agent workflows for image generation: plan→sketch→refine patterns, iterative improvement loops, self-critique approaches, multi-agent collaboration for scientific figures.

## Subtopic 3: Prompt Engineering for Scientific Images
Best practices, techniques, and examples for prompting image models to produce accurate scientific diagrams, equations, schematics, and technical visualizations. Domain-specific strategies.

## Subtopic 4: Agent Skills & Tools for Scientific Visualization
Existing frameworks, MCP servers, libraries, and tools that agents can use to generate or enhance scientific images (matplotlib, manim, tikz, plotly, draw.io programmatic, etc.)

## Subtopic 5: Emerging Approaches & Research
New techniques, academic research, frameworks specifically targeting AI-generated scientific figures, diagram-to-code, code-to-diagram, and hybrid approaches.

## Synthesis
Combine findings to recommend optimal approach for the drill-down explainer project: which models, which pipeline architecture, which prompts, which tools.
