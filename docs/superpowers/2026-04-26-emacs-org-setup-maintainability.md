## 2. How Everything Connects

### Launch sequence

```
emacs
  └─ loads early-init.el (Doom bootstrap)
       └─ loads init.el (your module declarations)
            └─ straight.el clones + builds all packages
                 └─ loads config.org (your settings)
                      └─ Emacs is ready
```

### Org-babel visualization pipeline

```
Org buffer with #+begin_src python
  │
  ├─ :prologue loads header.py       → dark theme + COLORS
  ├─ :results file :file fig.png     → output format
  ├─ C-c C-c executes block          → runs Python
  │    └─ Matplotlib/Altair/Schemdraw renders
  │         └─ PNG/SVG saved to disk
  └─ #+RESULTS: [[file:fig.png]]      → inline preview
```

### Agent-driven visualization pipeline

```
Org prompt → gptel / org-ai / opencode.el
              │
              ├─ Agent skill loaded (e.g., davila7/manim)
              ├─ Skill references taxonomy/*.yaml for concept mapping
              ├─ Skill uses code-patterns/*.py for render functions
              ├─ Skill follows UX rules from nine-patterns.yaml
              └─ Output artifact → linked in Org
```

### PKM data flow

```
Elfeed (arXiv feeds)
  └─ Find paper → download PDF
       └─ org-noter (annotation) → literature/ note
            └─ org-roam-bibtex (link bibliography)
                 └─ Synthesize → notes/ concept note
                      └─ org-ql (query across all notes)
```

## 3. Update Procedures

### When to update what

| Component | Frequency | Risk | Command |
|---|---|---|---|
| Emacs | Every 6-12 months | Medium | `winget upgrade GNU.Emacs` |
| Doom | Monthly | Low | `doom upgrade` |
| Packages | After Doom upgrade | Low | `doom sync -u` |
| Python frameworks | When needed | Low | `pip install --upgrade <pkg>` |
| Agent skills | Weekly | Low | `npx skills update` |

### 3.1 Update Doom Emacs

```powershell
# 1. Update Doom core
& "$env:USERPROFILE\.emacs.d\bin\doom.ps1" upgrade

# 2. Re-sync all packages
& "$env:USERPROFILE\.emacs.d\bin\doom.ps1" sync -u

# 3. Run health check
& "$env:USERPROFILE\.emacs.d\bin\doom.ps1" doctor
```

**If upgrade breaks:** See [Section 7: Recovery Procedures](#7-recovery-procedures).

### 3.2 Update Emacs itself

```powershell
# Check current version
emacs --version

# Upgrade via winget
winget upgrade GNU.Emacs

# After upgrade, refresh Doom
& "$env:USERPROFILE\.emacs.d\bin\doom.ps1" sync --rebuild
```

**Note:** New Emacs major versions may break packages. Wait 1-2 weeks after a release before upgrading, and check Doom's issue tracker.

### 3.3 Update Python frameworks

```powershell
# Update all installed frameworks
pip install --upgrade matplotlib seaborn plotly polars schemdraw altair manim pyvista moviepy datashader drawsvg pyyaml

# Verify nothing broke
python C:/Users/Bapti/docs/superpowers/viz-framework/install/verify-install.py
```

### 3.4 Update agent skills

```bash
# Check for updates
npx skills check

# Apply all updates
npx skills update
```

### 3.5 Add a new Doom module

1. Edit `~/.doom.d/init.el` — add the module to the appropriate section
2. Run `doom sync`
3. Add any configuration to `~/.doom.d/config.org`

### 3.6 Add a new MELPA package

1. Add to `~/.doom.d/packages.el`:
   ```elisp
   (package! package-name)
   ```
2. Add configuration to `~/.doom.d/config.org`:
   ```org
   * Package Name
   (use-package! package-name
     :config
     (setq package-name-setting value))
   ```
3. Run `doom sync`

## 4. Troubleshooting

### 4.1 Emacs won't start

```powershell
# 1. Check Emacs is on PATH
emacs --version

# 2. Start with vanilla config (bypass Doom)
emacs --no-init-file

# 3. Check for Doom errors
& "$env:USERPROFILE\.emacs.d\bin\doom.ps1" doctor

# 4. Check recent logs
Get-Content "C:/Users/Bapti/.emacs.d/.local/state/logs/" -Recurse | Select-String "Error" | Select-Object -Last 20
```

### 4.2 Package build errors (like evil-anzu)

```powershell
# Remove the broken package repo and re-sync
Remove-Item -Recurse -Force "C:/Users/Bapti/.emacs.d/.local/straight/repos/<package-name>"
& "$env:USERPROFILE\.emacs.d\bin\doom.ps1" sync -u
```

### 4.3 Doom sync hangs or times out

```powershell
# Kill any lingering Emacs processes
Get-Process emacs -ErrorAction SilentlyContinue | Stop-Process -Force

# Clear straight's build cache
Remove-Item -Recurse -Force "C:/Users/Bapti/.emacs.d/.local/straight/build"

# Rebuild everything
& "$env:USERPROFILE\.emacs.d\bin\doom.ps1" sync --rebuild
```

### 4.4 Org-babel blocks don't execute

```powershell
# 1. Verify header.py exists and loads
python -c "exec(open('C:/Users/Bapti/.emacs.d/header.py').read()); print('header.py OK')"

# 2. Check ob-python is enabled
# In Emacs: M-x org-babel-do-load-languages
# Verify python is in the list

# 3. Test a minimal block in Org:
# #+begin_src python :results output
#   print("test")
# #+end_src
# C-c C-c → should print "test"
```

### 4.5 Python blocks fail with import errors

```powershell
# Check which Python Emacs is using
# In Emacs: M-: (executable-find "python")
# Should return a path

# Install missing packages
pip install <missing-package>

# If using conda, ensure the correct env is activated
# In config.org:
# (setq doom-python-conda-env "my-env")
```

### 4.6 Diagrams (Mermaid/Graphviz) don't render

```powershell
# Mermaid: install mmdc
npm install -g @mermaid-js/mermaid-cli

# Graphviz: install dot
winget install Graphviz.Graphviz
# Then verify:
dot -V
```

### 4.7 Fonts not rendering (icons showing as boxes)

Install the required fonts:
1. Download JetBrains Mono: https://www.jetbrains.com/lp/mono/
2. Download Iosevka: https://github.com/be5invis/Iosevka/releases
3. Install `all-the-icons` fonts:
   ```
   # In Emacs: M-x all-the-icons-install-fonts
   ```

### 4.8 Emacs PATH doesn't include tool directories

```powershell
# Permanently add Emacs to user PATH
[Environment]::SetEnvironmentVariable(
    "Path",
    "C:\Program Files\Emacs\emacs-30.2\bin;" + [Environment]::GetEnvironmentVariable("Path", "User"),
    "User"
)
```

## 5. Backup & Restore

### What to back up (small, critical configs)

```powershell
# These are YOUR files — everything else is reproducible
Copy-Item -Recurse C:/Users/Bapti/.doom.d C:/Users/Bapti/org C:/Users/Bapti/.emacs.d/header.py D:/Backup/emacs/
```

**Minimum backup:** `.doom.d/` + `org/` + `header.py`. Everything under `.emacs.d/` is re-clonable.

### Git backup (recommended)

```powershell
# The home directory is already a git repo
# Commit any changes regularly
git -C C:/Users/Bapti add .doom.d/ org/ .emacs.d/header.py
git -C C:/Users/Bapti commit -m "chore: regular emacs config backup"
```

### Restore from scratch

```powershell
# 1. Install Emacs
winget install GNU.Emacs

# 2. Install Git if needed
winget install Git.Git

# 3. Clone Doom
git clone --depth 1 https://github.com/doomemacs/doomemacs "$env:USERPROFILE\.emacs.d"

# 4. Restore YOUR config
git clone <your-repo> "$env:USERPROFILE\"
# Or manually restore .doom.d/, org/, .emacs.d/header.py

# 5. Install Doom
& "$env:USERPROFILE\.emacs.d\bin\doom.ps1" install

# 6. Sync packages
& "$env:USERPROFILE\.emacs.d\bin\doom.ps1" sync

# 7. Install Python frameworks
pip install matplotlib seaborn plotly polars schemdraw altair manim pyvista moviepy datashader drawsvg pyyaml

# 8. Install agent skills
npx skills add heygen-com/hyperframes@hyperframes -g -y
npx skills add adithya-s-k/manim_skill@manimce-best-practices -g -y
npx skills add softaworks/agent-toolkit@mermaid-diagrams -g -y
npx skills add markdown-viewer/skills@graphviz -g -y
```

## 6. Known Issues

### 6.1 JavaScript inline rendering
**Problem:** Plotly, D3.js, Three.js outputs (HTML) cannot render inline in Org.
**Workaround:** Open `.html` files in browser. Org is the orchestrator, not the renderer.

### 6.2 WSL2 electronics tools
**Problem:** Xschem, Magic, Netgen require WSL2 (Linux-native).
**Workaround:** Install WSL2 (`wsl --install`), then install tools inside WSL. Use `wsl.exe ngspice` from Emacs on Windows.

### 6.3 First launch is slow
**Problem:** First `emacs` launch after sync compiles many `.elc` files.
**Workaround:** This only happens once. Subsequent launches are fast (~2-3 seconds with Doom daemon).

### 6.4 evil-anzu package build failure
**Problem:** `evil-anzu` sometimes fails to clone during `doom sync` (git HEAD resolution).
**Impact:** Cosmetic only — the `anzu` package shows search match counts. Non-critical.
**Fix:** `Remove-Item -Recurse -Force ~/.emacs.d/.local/straight/repos/evil-anzu` then `doom sync`.

### 6.5 Windows PATH with PowerShell
**Problem:** Emacs may not be on PATH in some PowerShell sessions.
**Fix:** The installer adds it permanently to User PATH. If missing, run:
```powershell
$env:Path = [Environment]::GetEnvironmentVariable("Path", "Machine") + ";" + [Environment]::GetEnvironmentVariable("Path", "User")
```

### 6.6 Org-babel plots show but don't update
**Problem:** Cached inline images in Org buffers.
**Fix:** `C-c C-c` on the block re-renders. Or `M-x org-redisplay-inline-images`.

## 7. Recovery Procedures

### 7.1 Full Doom reset (nuclear option)

```powershell
# 1. Backup your config
Copy-Item -Recurse C:/Users/Bapti/.doom.d C:/Users/Bapti/org D:/Backup/

# 2. Delete Doom state
Remove-Item -Recurse -Force C:/Users/Bapti/.emacs.d/.local

# 3. Re-install Doom
& "$env:USERPROFILE\.emacs.d\bin\doom.ps1" install

# 4. Sync fresh
& "$env:USERPROFILE\.emacs.d\bin\doom.ps1" sync
```

### 7.2 Reset a specific package

```powershell
# Remove the package and rebuild
Remove-Item -Recurse -Force "C:/Users/Bapti/.emacs.d/.local/straight/repos/<package>"
Remove-Item -Recurse -Force "C:/Users/Bapti/.emacs.d/.local/straight/build/<package>"
& "$env:USERPROFILE\.emacs.d\bin\doom.ps1" sync
```

### 7.3 Emacs won't start at all

```powershell
# Try with vanilla config
emacs --no-init-file

# If that works, it's a config issue
# Start Emacs with debug enabled
emacs --debug-init

# Check the \*Messages\* buffer for errors
```

### 7.4 Rollback a bad config change

```powershell
# Use git to revert
git -C C:/Users/Bapti log --oneline -10 .doom.d/config.org
git -C C:/Users/Bapti checkout <commit-hash> -- .doom.d/config.org
& "$env:USERPROFILE\.emacs.d\bin\doom.ps1" sync
```

## 8. Useful Commands Cheatsheet

### Doom CLI

```powershell
# Set alias first for convenience
$doom = "$env:USERPROFILE\.emacs.d\bin\doom.ps1"

& $doom sync                    # Install/update packages
& $doom sync -u                 # Sync + update packages
& $doom upgrade                 # Upgrade Doom itself
& $doom doctor                  # Health check
& $doom purge                   # Remove orphaned packages
& $doom clean                   # Garbage collection
& $doom env                     # Regenerate env file
```

### Emacs

```powershell
emacs                           # Launch normally
emacs --debug-init              # Launch with debug output
emacs --no-init-file            # Launch without config
emacs --batch -l script.el      # Run script headless
```

### Org-babel (in Emacs)

```
C-c C-c           Execute source block at point
C-c C-v C-b       Execute all blocks in buffer
C-c C-v C-s       Execute all blocks in subtree
C-c C-v C-t       Tangle (extract code to files)
C-c C-c on #+RESULTS image  Toggle inline image display
```

### Keybindings

```
SPC f f           Find file
SPC f r           Recent files
SPC b b           Switch buffer
SPC /             Project search (ripgrep)
SPC g g           Magit status
SPC n f           Org-roam find node
SPC n c           Org-roam capture
SPC n b           Org-roam backlinks
SPC a c           gptel chat
SPC a b           org-ai block
SPC t e           Toggle evil-mode
C-c C-p           Graphviz preview (in .dot file)
```

### Python verification

```powershell
# Full framework check
python C:/Users/Bapti/docs/superpowers/viz-framework/install/verify-install.py

# Pipeline verification
python C:/Users/Bapti/docs/superpowers/viz-framework/verify-pipeline.py

# Quick check: header loads
python -c "exec(open('C:/Users/Bapti/.emacs.d/header.py').read()); print('OK')"
```

### Agent skills

```bash
npx skills list                    # What's installed
npx skills check                   # Check for updates
npx skills update                  # Update all
npx skills find <query>            # Search for new skills
npx skills add <skill> -g -y       # Install a skill
```
