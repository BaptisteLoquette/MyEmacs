* Deep FPGA: Physics, Math, Electronics and ML/HPC Acceleration

A frontier-level, dependency-aware curriculum for engineers and researchers who want to master FPGA internals from semiconductor physics through board-level electronics, mathematical foundations, Verilog RTL, data structures, prototyping tools (Python / Julia / MATLAB), and culminating in ML/AI acceleration and HPC architectures.

** Prerequisites assumed
- Bachelor-level digital logic and programming.
- This curriculum assumes Python proficiency; MATLAB access is helpful but not required.

** How to use this plan
- Each leaf heading is an atomic concept designed for 20–40 minutes of focused study.
- Follow the order; concepts depend on earlier ones.
- For each concept, read the Theory source first, then attempt the Hands-on exercise.
